One original line of fortune-cookie wisdom for a software developer:

> A test you never watched fail is a rumor, not a safeguard.

A test only proves something when you have watched it go red. A test that
has never failed has never shown it can catch anything — so all it really
is, is a rumor that your code works.

## Run it

```sh
python3 main.py
```

This writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
